# sdl.life

Astro static website for deployment to Cloudflare Workers Static Assets.

## Stack

- Astro (static output)
- TypeScript
- Tailwind CSS
- Astro Content Collections
- Cloudflare Workers Static Assets (`wrangler.toml`)

## Commands

- `npm run dev`
- `npm run build`
- `npm run deploy`

## Deployment model

This project is fully static. There is no Astro adapter and no server rendering at runtime.
